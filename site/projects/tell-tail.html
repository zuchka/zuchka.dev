Tell-Tail

See what your tools did.

Tell-Tail is the open-source Rust tool I build for inspecting tool calls and application logs on my own machine. I use its local dashboard to find a failed call and see which server handled it.

Try a tool-call trace

The built-in demo opens the AI Activity timeline with sample events. Select a call to inspect its tool, duration, and outcome.

brew install ding-labs/tap/tell-tail
tell-tail desktop --demo --open

For a live session, the tracing guide explains how to capture tool results from Codex.

Follow an application log

Point Tell-Tail at a file your application is writing. The Logs workspace shows throughput, warnings, and recent errors as new lines arrive.

tell-tail app.log --output web --open

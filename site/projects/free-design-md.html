What it does

Free Design.md loads a public page in a real browser and reads its computed styles. The deterministic pass turns what it finds into structured Markdown: foundations, tokens, type, spacing, radii, and recurring component patterns. That extraction is free and does not need an account or a language model.

If the raw artifact needs more interpretation, optional AI enrichment adds higher-level guidance: composition, brand voice, component behavior, and practical do's and don'ts. The result can be downloaded as Markdown, HTML, or MDX. 

# from the public API
curl "https://freedesign.md/api/extract?url=https://stripe.com&format=json"

Why a Markdown design system

Screenshots show the result, but not the rules behind it. Token files capture values, but usually miss composition and component behavior. A design.md sits in the useful middle: compact enough to read and review, structured enough to guide implementation, and plain text enough to travel anywhere.

  • Agent-readable — give coding agents concrete design context before they write UI.
  • Portable — keep it in Git, paste it into chat, or publish it with the rest of the docs.
  • Inspectable — edit the Markdown directly; there is no proprietary format between you and the output.
  • Self-hostable — run the same workflow locally in Docker and keep model keys in your own environment.

The open catalog

The companion catalog contains 77 ready-made design.md files spanning developer tools, commerce, automotive, media, SaaS, and even a few period-specific web designs. It is both a useful starting library and a public record of what the extractor produces.

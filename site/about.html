About

Matt Abrams. Full-stack engineer in the United States.

I build product end-to-end: backend systems, web frontends, the small CLIs that keep shipping bearable. I also maintain a handful of open-source libraries — most visibly remove-markdown, which has somehow accumulated 800k weekly npm downloads since I wrote it in 2015.

What I work on

I gravitate toward the boring-but-load-bearing parts of a stack: API design that ages well, observability that actually fires when things break, dev tooling that the team forgets exists because it just works. Currently building DING, an alert engine for ephemeral compute — the kind of monitoring problem Prometheus wasn't designed for.

I'm a generalist by inclination. Comfortable in Go, TypeScript, JavaScript, Python; happy enough in C when I have to be. More interested in the system above the language than the language itself.

About

I'm Matt Abrams, a developer experience (DX) engineer and developer advocate in Los Angeles.

I build products end-to-end: backend systems, web frontends, the small CLIs that keep shipping bearable. I also maintain a handful of open-source libraries — most visibly remove-markdown, which has somehow accumulated over 1 million weekly npm downloads.

I came up through developer advocacy and community engineering — Grafana Labs, Railway, Builder.io — so I think about the people building with software as much as the software itself.

What I work on

I gravitate toward the boring-but-load-bearing parts of a stack: API design that ages well, observability that actually fires when things break, dev tooling that the team forgets exists because it just works.

Currently building Ding, which gives developers and agents persistent watches and inspectable alerts, and Free Design.md, which turns public websites into portable design context.

I'm a generalist by inclination. Comfortable in Go, TypeScript, JavaScript, Python; happy enough in C when I have to be. More interested in the system above the language than the language itself.
